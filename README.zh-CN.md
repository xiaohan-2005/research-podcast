# Research Podcast

**把论文变成能听懂的播客，但不把证据变成“听起来很对”。**

Research Podcast 是一个面向 Codex / Agent Skills 工作流的科研音频 Skill。它可以把论文、PDF、研究报告、课堂笔记或多份文献转换成自然的双人播客，同时保留完整的证据追踪链。

## 核心差异
普通“文档转播客”首先追求顺滑；这个项目首先保证：

`原始材料 → source map → 对话 claim → 校验 → TTS`

因此它更适合科研和学习，而不只是内容消费。

## 四种模式
- **deep-dive**：研究问题 → 方法 → 结果 → 含义 → 局限
- **exam-review**：概念讲解 + 易错点 + 主动回忆问题
- **defense**：模拟答辩，一方讲、一方像评委追问
- **briefing**：多文献快速对比，只保留有证据的结论

## 为什么要做 source map
播客对白很容易把“合理推测”说成“论文结论”。本 Skill 要求每个事实性或解释性发言都绑定 `source_ids`，并在音频生成前检查无效引用和无证据 claim。

## 适合的使用方式
```text
把这篇 40 页论文做成 8 分钟中文 deep-dive，尤其解释模型为什么这样设计。

把概率图模型这一章做成期末复习播客，重点拆解易混概念。

把我的论文做成答辩模拟，评委要追问数据、假设和局限。
```

## 和普通播客 Skill 的区别
它不是单纯的 TTS 包装。真正的产品能力是“科研内容理解 + 证据映射 + 对话化重构 + 自动校验 + 音频生成”。
